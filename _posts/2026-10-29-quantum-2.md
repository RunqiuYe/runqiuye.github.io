## Query complexity

After discussing $\mathsf{BQP}$, we introduce another tool for comparing the power
of quantum and classical computation — **query complexity**. This can
be compared to the oracle complexity in classical setting, namely we have
an oracle machine that tells us answer in one step when we give an input.
In the query complexity setting, we can also learn things about a hidden
function by providing input, and the number of times we need to query the
function to learn the property is the new measure of complexity.

For a simple example, consider some satisfiability problem characterized
by a function $f : \lbrace0, 1\rbrace^n \to \lbrace0, 1\rbrace$, and we would like to know if
there exists $x \in \lbrace0, 1\rbrace^n$ such that $f(x) = 1$. This is very similar
to 3SAT, and we can only query $f$ on input $x \in \lbrace0, 1\rbrace^n$ one at a
time. If there is at most one possible input $x$ such that $f(x) = 1$, we
have to make exponentially many queries to determine if such an $x$
exists.

To make this model more concrete, we first need to define a
**quantum oracle**. There are two useful notion, the first of which
is the **standard oracle**. The standard oracle $B_f$ acts on two
registers:

$$
B_f \left\lvert x\right\rangle \left\lvert b\right\rangle = \left\lvert x\right\rangle \left\lvert b \oplus f(x)\right\rangle.
$$

Another useful model is the **phase oracle** $O_f$, defined via

$$
O_f \left\lvert x\right\rangle = (-1)^{f(x)} \left\lvert x\right\rangle.
$$

The standard oracle $B_f$ can simulate the phase oracle $O_f$. Indeed,

$$
B_f \left\lvert x\right\rangle \left\lvert -\right\rangle
= \left\lvert x\right\rangle \left( \frac{\left\lvert f(x)\right\rangle - \left\lvert 1 \oplus f(x)\right\rangle}{\sqrt{2}} \right)
= (-1)^{f(x)} \left\lvert x\right\rangle \left\lvert -\right\rangle
= (O_f \left\lvert x\right\rangle) \left\lvert -\right\rangle.
$$

The reverse simulation is not possible from $O_f$ as defined here
without additional access, such as controlled access to $O_f$: the phase
oracles for $f$ and $1 - f$ differ only by an unobservable global phase,
whereas their standard oracles are distinct.

To see a very simple example that quantum algorithm has advantage over
classical algorithm in terms of query complexity, consider the problem of
determining if a function $f : \lbrace0, 1\rbrace \to \lbrace0, 1\rbrace$ is constant or not,
i.e. if $f(0) = f(1)$. Classically, it is clear that we need two queries,
but we claim ther is a quantum circuit for this problem using only one
queries. Indeed, consider a circuit given by $H O_f H \left\lvert 0\right\rangle$. Then we
have

$$
\begin{aligned}
\left\lvert 0\right\rangle
 & \xrightarrow{H} \frac{\left\lvert 0\right\rangle + \left\lvert 1\right\rangle}{\sqrt{2}}
\xrightarrow{O_f} \frac{(-1)^{f(0)} \left\lvert 0\right\rangle + (-1)^{f(1)} \left\lvert 1\right\rangle}{\sqrt{2}}
= (-1)^{f(0)} \left( \frac{\left\lvert 0\right\rangle + (-1)^{f(0) \oplus f(1)} \left\lvert 1\right\rangle}{\sqrt{2}} \right) \\
 & \xrightarrow{H} (-1)^{f(0)} \left\lvert f(0) \oplus f(1)\right\rangle.
\end{aligned}
$$

Therefore, if $f(0) = f(1)$, we will measure $\left\lvert 0\right\rangle$ with probability
$1$, and otherwise if $f(0) \neq f(1)$, we will measure $\left\lvert 1\right\rangle$ with
probability $1$.

This phenomenon where quantum algorithm has advantage over classical
algorithm is called **quantum-classical separation**.

## The unstructured search problem and lower bound

Now let us discuss a more complicated problem where there is
quantum-classical separation — the unstructured search problem. The
unstructured search problem is defined as follows: given a function $f : \lbrace0, 1\rbrace^{n} \to \lbrace0, 1\rbrace$ which we can query, we try to find $x \in \lbrace0, 1\rbrace^n$ such that $f(x) = 1$ or report none exists.

Again, notice that this is very similar to 3SAT. In fact, all problems in
$\mathsf{NP}$ can be phrased as unstructured search problems. Unfortunately in a
classical setting, exponentially many classical queries are required.
Indeed, consider the case where there is at most one input which evaluates
to $1$. Any classical deterministic algorithm may need to make all $2^n$
queries: after receiving $0$ on the first $2^n - 1$ inputs, it must still
query the final input to distinguish a marked final input from the
all-zero function. Randomness does not help — even if half of all inputs
are queried, we only have $1/2$ chance at choosing the input that
evaluates to $1$.

Unfortunately, there is no quantum circuits that achieves polynomial query
complexity in the unstructured search problem. The following theorem by
Bennett, Bernstein, Brassard, Vazirani gives a lower bound of the quantum
query complexity for the unstructured search complexity, known as the
**BBBV lower bound**. This theorem states that the quantum query
complexity of unstructured search problem is $\Omega (\sqrt{2^n})$. We
present the proof now.

First notice that a generic quantum query algorithm alternates between
applying some unitary and applying some oracle. That is, after $t$
queries, the state of the system is

$$
U_t O_f U_{t - 1} \dots U_1 O_f \left\lvert 0^n\right\rangle.
$$

A key point is that the unitaries $U_1, \dots, U_t$ are fixed and are
independent of what the oracle does. Our goal will be to show that for
any choice of unitaries, there is some state $\left\lvert y\right\rangle$ that always has
small amplitude when queried by the oracle. Becuase of this, it will be
difficult for the algorithm to see if this item returns $1$, thus fail
to distinguish the constant zero function and some other $f$.

First consider the behavior on the constant zero function. Now $O_f = I$
and the algorithm should reject. After $t$ queries, the state is

$$
\left\lvert \psi_t\right\rangle
:= U_t U_{t - 1} \dots U_1 \left\lvert 0^n\right\rangle
= \sum_{x \in \lbrace0, 1\rbrace^n} \alpha_{x, t} \left\lvert x\right\rangle.
$$

Suppose there are $T$ total queries, and define

$$
m_x := \sum_{t = 0}^{T - 1} \left\lvert \alpha_{x, t}\right\rvert^2 \geq 0.
$$

Note that

$$
\sum_{x \in \lbrace0, 1\rbrace^n} m_x
= \sum_{x \in \lbrace0, 1\rbrace^n} \sum_{t = 0}^{T - 1} \left\lvert \alpha_{x, t}\right\rvert^2
= \sum_{t = 0}^{T - 1} \sum_{x \in \lbrace0, 1\rbrace^n}  \left\lvert \alpha_{x, t}\right\rvert^2
= T.
$$

Therfore, there must exists some $y \in \lbrace0, 1\rbrace^n$ such that $m_y \leq 2^{-n} T$. Moreover, by Cauchy-Schwarz, we have

$$
\sum_{t = 0}^{T - 1} \left\lvert \alpha_{y, t}\right\rvert
\leq \sqrt{T \sum_{t = 0}^{T - 1} \left\lvert \alpha_{y, t}\right\rvert^2}
= \sqrt{m_y T}
\leq 2^{-n / 2} T.
$$

Refer to the constant zero function as the identity, and let $f$ be the
function which is $1$ on $y$ and $0$ otherwise. Our goal is to
distinguish the oracle for $f$ from the oracle for the identity. Let's
consider a set of oracles $\lbrace O^{(t)} \rbrace_{t = 0}^T$, where $O^{(t)}$ is
defined to be the identity for first $t$ queries and $f$ on the
remaining $T - t$ queries. Now define

$$
\left\lvert \varphi^{(t)}\right\rangle
:= U_T O^{(t)} U_{T - 1} \dots O^{(t)} U_1 \left\lvert 0^n\right\rangle
= U_T O_f U_{T - 1} \dots O_f U_{t + 1} O_f \left\lvert \psi_t\right\rangle.
$$

In particular, $\left\lvert \varphi^{(T)}\right\rangle = \left\lvert \psi_T\right\rangle$ is the result state
of the algorithm on the zero function, and $\left\lvert \varphi^{(0)}\right\rangle$ is the
result state of the algorithm on the $f$ we defined. Note that $O_f \left\lvert \psi_t\right\rangle = \left\lvert \psi_t\right\rangle - 2 \alpha_{y, t} \left\lvert y\right\rangle$, and unitary
maps are norm-preserving. It follows that for all $t$, we have

$$
\begin{aligned}
\left\lVert \left\lvert \varphi^{(t + 1)}\right\rangle - \left\lvert \varphi^{(t)}\right\rangle\right\rVert
 & = \left\lVert U_T O_f \dots U_{t + 2} O_f \left\lvert \psi_{t + 1}\right\rangle
       - U_T O_f \dots U_{t + 2} O_f U_{t + 1} O_f \left\lvert \psi_t\right\rangle\right\rVert   \\
 & = \left\lVert (U_T O_f \dots U_{t + 2} O_f U_{t + 1}) \left\lvert \psi_t\right\rangle
       - (U_T O_f \dots U_{t + 2} O_f U_{t + 1}) O_f \left\lvert \psi_t\right\rangle\right\rVert \\
 & = \left\lVert \left\lvert \psi_t\right\rangle - O_f \left\lvert \psi_t\right\rangle\right\rVert                       \\
 & = 2 \left\lvert \alpha_{y, t}\right\rvert.
\end{aligned}
$$

Therefore,

$$
\left\lVert \left\lvert \varphi^{(T)}\right\rangle - \left\lvert \varphi^{(0)}\right\rangle\right\rVert
\leq \sum_{t = 0}^{T - 1} \left\lVert \left\lvert \varphi^{(t + 1)}\right\rangle - \left\lvert \varphi^{(t)}\right\rangle\right\rVert
\leq 2 \sum_{t = 0}^{T - 1} \left\lvert \alpha_{y, t}\right\rvert
\leq \frac{2 T}{\sqrt{2^n}}.
$$

Hence, if $T = o (\sqrt{2^n})$, thenn the two states are closed under
the $2$-norm, and all measurement fail to distinguish them with high
probability. To formalize this, recall the **total variation** of
two discrete probability distribution $p, q$:

$$
\operatorname{TV}(p, q)
= \frac{1}{2} \left\lVert p - q\right\rVert_1
= \frac{1}{2} \sum_i \left\lvert p_i - q_i\right\rvert.
$$

Total variation determines the maximum probability with which we can
distinguish two probability distributions. Suppose we sample from $p$
with $1/2$ chance and sample from $q$ with $1/2$ chance, the maximum
probability we can infer the distribution sampled from is $1/2 + \operatorname{TV} (p, q) / 2$. Apply the following lemma, we can convert
our current bound on the $2$-norm to $1$-norm for the cost of a
constant. Therefore, we can conclude that $T = \Omega(2^{n / 2})$.

**Lemma.** If $\left\lVert \left\lvert \varphi\right\rangle - \left\lvert \psi\right\rangle\right\rVert_2 < \varepsilon$, then
$\operatorname{TV} (\left\lvert \varphi\right\rangle, \left\lvert \psi\right\rangle) \leq 2 \varepsilon$.

## Grover's algorithm

With a $\Omega(\sqrt{2^n})$ lower bound, it is natural to wonder if there
is an algorithm that runs in $O(\sqrt{2^n})$ time. The answer is yes, with
Grover's algorithm.

It turns out that Grover's algorithm depends on the number of input $x$
such that $f(x) = 1$. For simplicity, assume first that there is only one
marked item.

### Grover diffusion operator

We first introduce the **Grover diffusion operator**, which is
crucial for the algorithm. Its definition is

$$
D = 2 \left\lvert u\right\rangle \left\langle u \right\rvert - I,
$$

where $\left\lvert u\right\rangle = H^{\otimes n} \left\lvert 0^n\right\rangle$ is the uniform
superposition.

Claim that $D$ is a unitary operator that reflects about $\left\lvert u\right\rangle$.
Moreover, $D$ can be constructed with linearly many gates in log depth. To
show $D$ is unitary, note that

$$
D D^{\ast}
= (2 \left\lvert u\right\rangle \left\langle u \right\rvert - I) (2 \left\lvert u\right\rangle \left\langle u \right\rvert - I)^{\ast}
= 4 \left\lvert u\right\rangle \left\langle u \right\rvert - 2 \left\lvert u\right\rangle \left\langle u \right\rvert - 2 \left\lvert u\right\rangle \left\langle u \right\rvert  + I
= I.
$$

To see $D$ is a reflection about $\left\lvert u\right\rangle$, consider decomposing any
state $\left\lvert \psi\right\rangle$ orthoganlly:

$$
\left\lvert \psi\right\rangle = \alpha \left\lvert u\right\rangle + \beta \left\lvert v\right\rangle,
$$

where $\left\langle u \mid v \right\rangle = 0$. Then,

$$
D \left\lvert \psi\right\rangle
= \alpha (2 \left\lvert u\right\rangle \left\langle u \right\rvert - I) \left\lvert u\right\rangle
+ \beta (2 \left\lvert u\right\rangle \left\langle u \right\rvert - I) \left\lvert v\right\rangle
= \alpha \left\lvert u\right\rangle - \beta \left\lvert v\right\rangle.
$$

To see $D$ can be constructed with linearly many gates in log depth,
notice that $H^{\otimes n} D H^{\otimes n} = 2 \left\lvert 0^n\right\rangle \left\langle 0^n \right\rvert - I$.
Call this $D_0$ and we just need a circuit for $D_0$. On the basis, we
have $D_0 \left\lvert x\right\rangle = (-1)^{x_1 \vee \dots \vee x_n} \left\lvert x\right\rangle$, so we just
need to detect if any of the qubits are $1$, which is doable with a
linear-size, log-depth circuit. Then we apply a phase gate for the answer.

### Grover's algorithm

Recall the problem statement, we want to output the marked element $s \in \lbrace0, 1\rbrace^n$ such that $f(s) = 1$, or report none exists. The algorithm is
as follows: let $\left\lvert \psi_0\right\rangle = H^{\otimes n} \left\lvert 0^n\right\rangle = \left\lvert u\right\rangle$, and
compute $\left\lvert \psi_T\right\rangle = (D O_f)^T \left\lvert \psi_0\right\rangle$. Let $s^{\ast}$ be a
meausrement of $\left\lvert \psi_T\right\rangle$, and return $s^{\ast}$ if $f(s^{\ast}) = 1$,
otherwise return none. The constant $T$ that depend only on the number of
marked item (assumed to be $1$ now) will be determined later.

To understand why this works, take a geometric perspective. Our initial
state $\left\lvert u\right\rangle$ lies in the span of $\left\lvert s\right\rangle$ and $\left\lvert \Psi\right\rangle = \frac{1}{\sqrt{2^n - 1}} \sum_{x \neq s} \left\lvert x\right\rangle$, which is the uniform
superposition of unmarked item. Indeed,

$$
\left\lvert u\right\rangle
= \frac{1}{\sqrt{2^n}} \sum_x \left\lvert x\right\rangle
= \frac{1}{\sqrt{2^n}} \left\lvert s\right\rangle + \frac{1}{\sqrt{2^n}} \sum_{x \neq s} \left\lvert x\right\rangle
= \frac{1}{\sqrt{2^n}} \left\lvert s\right\rangle + \sqrt{1 - 2^{-n}} \left\lvert \Psi\right\rangle.
$$

Inductively, each iteration $\left\lvert \psi_t\right\rangle = (D O_f)^t \left\lvert \psi_0\right\rangle$ is
in the span of $\left\lvert s\right\rangle$ and $\left\lvert \Psi\right\rangle$. Indeed, we have $\alpha \left\lvert s\right\rangle + \beta \left\lvert \Psi\right\rangle \xrightarrow{O_f} - \alpha \left\lvert s\right\rangle + \beta \left\lvert \Psi\right\rangle$, and

$$
\alpha \left\lvert s\right\rangle + \beta \left\lvert \Psi\right\rangle
\xrightarrow{D} (2 \left\lvert u\right\rangle \left\langle u \right\rvert - I)
(\alpha \left\lvert s\right\rangle + \beta \left\lvert \Psi\right\rangle)
= 2 (\alpha \left\langle u \mid s \right\rangle + \beta \left\langle u \mid \Psi \right\rangle) \left\lvert u\right\rangle
- \alpha \left\lvert s\right\rangle - \beta \left\lvert \Psi\right\rangle,
$$

where $\left\lvert u\right\rangle$ is already shown to be in the span, thus completing the
proof.

Now, each iteration of $D O_f$ is a rotation in the plane spanned by
$\left\lvert s\right\rangle$ and $\left\lvert \Psi\right\rangle$. Note that $O_f$ reflects about $\left\lvert \Psi\right\rangle$
and $D$ reflects about $\left\lvert u\right\rangle$, as shown in the following figure:

Hence, the revolution of the angle is given by $\theta_0, 3 \theta_0, \dots, (2T + 1) \theta_0$. Notice that we want to reach $\pi / 2$, so we
need to choose $T \approx \pi / (4 \theta_0)$. On the other hand, we have

$$
\theta_0 \approx \sin (\theta_0) = \left\langle u \mid s \right\rangle = 2^{- n / 2}.
$$

Hence, we choose $T = O(\sqrt{2^n})$ and the query complexity of the
algorithm is $O(\sqrt{2^n})$. When $n$ is large enough, the final
position $(2 T + 1) \theta_0$ is also close enough to $\pi / 2$ to
guarantee the correct probaibility.

What if there is more than one marked element? Now let $\left\lvert s\right\rangle$ be the
uniform superposition of over all $x$ such that $f(x) = 1$. If we have $m$
such elements, then the initial angle is $\left\langle s \mid u \right\rangle \approx \sqrt{m 2^{-n}}$, at least when there are not too many marked element so this
angle is small. In the case where there are too many element, just
randomly sample until we find one. Then, in this case, $T = O(\sqrt{2^{n} m^{-1}})$. Finally, what if we don't know the number of marked elements?
The trick is “exponential search”. Namely, we make the following cases
for $m$: $2^n, 2^{n - 1}, \dots, 4, 2, 1$. If we make all $n$ possible
guesses, then we are at most a factor of $2$ off from the real $m$. We can
check this does not affect the correctness probability by a lot. The
reverse order also give us the $m^{-1/2}$ speedup when there are more than
$m$ marked element.

### Significance and limitations

To conclude, we discuss some significance and limitations of Grover's
algorithm. First of all, it shows a provable quantum advantage from
$O(2^n)$ query complexity to $O(\sqrt{2^n})$ quantum query complexity. The
BBBV $\Omega (\sqrt{2^n})$ lower bound also shows that Grover's algorithm
achieves the best possible generic quantum speedup for the unstructured
search problem. The unstructured search problem also has very general
applicability. Indeed, any efficiently verifiable $f(x)$ can potentially
be searched using this algorithm, and any $\mathsf{NP}$ problem can be expressed
as such a problem.

However, there are some limitations. Grover's algorithm only achieves a
quadratic speedup. This is substantial but not exponential, and it does
not make $\mathsf{NP}$-complete problem efficient. Moreover, the complexity is
phrased in terms of query complexity, and the oracle $O_f$ may be
expensive. Therefore, it does not give a realistic speedup without the
oracle. Also, for applications like databse search, there is little
advantange given by this algorithm. It only returns one element that
satisfies the condition. Loading $N$ items also already cost $O(N)$, so
the speedup is meaningless.
